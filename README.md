# স্মার্ট আয়কর ক্যালকুলেটর — বাংলাদেশ (v2)

বাংলাদেশের বেতনভোগী ও ব্যক্তি করদাতাদের জন্য একটি অফলাইন-সক্ষম (PWA) আয়কর ক্যালকুলেটর। এটি কোনো বিল্ড টুল ছাড়াই চলে: শুধু ফোল্ডারটা যেকোনো স্ট্যাটিক হোস্টে (GitHub Pages, Cloudflare Pages) রাখলেই হবে।

## ফাইল

| ফাইল | কাজ |
|---|---|
| `js/tax-rules.js` | **সব নিয়ম ও মান**: করমুক্ত সীমা, স্ল্যাব, রেয়াত, ন্যূনতম কর, বিনিয়োগ খাত, ডিফল্ট ইনপুট |
| `js/engine.js` | শুধু হিসাবের লজিক (DOM নেই, Node-এ টেস্ট করা যায়) |
| `js/app.js` | ইউজার ইন্টারফেস, নিয়ম-গাইড, সেটিংস, এক্সপোর্ট |
| `css/style.css` | ডিজাইন (লাইট/ডার্ক থিম) |
| `service-worker.js` | অফলাইন ক্যাশ। কোনো ফাইল বদলালে `CACHE_VERSION` বাড়ান |

## নতুন বাজেট এলে

1. `js/tax-rules.js` খুলুন
2. সবচেয়ে উপরের preset কপি করে উপরে বসান, `id`, `label` আর মানগুলো বদলান
3. নতুনটিতে `current: true` দিন, আর পুরনোটি থেকে তা মুছে দিন। `DEFAULT_INPUTS.presetId`-এও নতুন `id` দিন

ব্যবহারকারীরা কোড না ছুঁয়েই অ্যাপের **⚙️ সেটিংস** ট্যাব থেকে মান বদলাতে পারেন। বদলানো মান তাঁদের ব্রাউজারে থাকে, আর JSON হিসেবে এক্সপোর্ট/ইমপোর্টও করা যায়।

## হিসাবের ধাপ

1. বেতন আয় = ১২ মাসের বেতন (ইনক্রিমেন্টসহ) + বোনাস + নিয়োগকর্তার PF অংশ
2. অব্যাহতি = সর্বনিম্ন(বেতন আয় ÷ ৩, ৫,০০,০০০)
3. করযোগ্য আয় = বেতন আয় − অব্যাহতি + অন্যান্য আয়
4. স্ল্যাব অনুযায়ী কর (করদাতার শ্রেণির করমুক্ত সীমা + প্রতিবন্ধী সন্তানের ছাড়)
5. রেয়াত = সর্বনিম্ন(করযোগ্য আয়ের ৩%, যোগ্য বিনিয়োগের ১৫%, ১০,০০,০০০)
6. নিট কর = সর্বোচ্চ(কর − রেয়াত, ন্যূনতম কর)। আয় করমুক্ত সীমার নিচে হলে কোনো কর নেই
7. মাসিক কর্তন: ইনক্রিমেন্টের আগের মাসগুলোতে পুরনো বেতন ধরে কর কাটা হয়। বাকি কর পরের মাসগুলোতে ভাগ হয়

> এটি একটি আনুমানিক হিসাব। চূড়ান্ত রিটার্নের আগে NBR-এর সর্বশেষ প্রজ্ঞাপনের সঙ্গে মিলিয়ে নিন।
